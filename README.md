🚀 About PhishShield AI

PhishShield AI is an AI-powered cybersecurity project designed to detect phishing messages, fraudulent images, suspicious calls, and deepfake voices.

It aims to protect users by identifying digital threats and explaining security warnings in their preferred language.

🎯 Problem Statement

- Fake voice calls imitate familiar people.
- Fraudulent WhatsApp messages and links look genuine.
- Deepfake voices make scams harder to identify.
- Language barriers make cybersecurity difficult to understand.

💡 Our Solution

PhishShield AI combines multimodal AI and intelligent agents to identify suspicious activities, analyse threats, and provide multilingual warnings.

✨ Key Features

- 🎙️ Deepfake Voice Detection
- 📩 Scam Message Detection
- 🖼️ Fraudulent Image Scanning
- ⚡ Real-Time Protection (planned)
- 🌐 Multilingual Support
- 🚨 Threat Reporting

⚙️ How It Works

1. Scan: Analyses voice, text, and images.
2. Reason: Compares suspicious content with known scam patterns using RAG.
3. Explain: Generates warnings in the user's language.
4. Report: Helps log and report suspicious threats.

🧠 AI Agent Architecture

- Multimodal Scanner: Checks voice, text, and images.
- RAG Engine: Retrieves known scam patterns.
- Explainer Agent: Detects language and explains threats.
- Reporting Agent: Supports threat reporting.
